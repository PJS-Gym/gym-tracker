Floating pill confirmation. Mount one `ToastRegion` (a live region) per frame and swap the Toast inside it, so it is announced.
```jsx
<ToastRegion offset={100}>{toast && <Toast message="Set 3 removed" action={{label:"Undo",onAction:undo}}/>}</ToastRegion>
```
Neutral plum by default, PRs included ("New PR: bench 85 kg"); no celebratory colour. The toast repeats the action's verb ("Finish workout" → "Workout finished").
